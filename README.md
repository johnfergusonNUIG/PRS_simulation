## System Requirements

- **Software requirements to run code:** A recent version of the open source statistical program R, with the tidyverse, parallel and survival packages installed
- **Versions the software has been tested on:** The code has been tested on R version 4.5.1, installed on macOS (ARM). However, R code is platform independent, so the code will work on Windows and Linux installations of R.
- **Any required non standard hardware:** Not applicable

## Installation guide

- **Instructions:** Code is R source code. No installation necessary.
- **Typical install time:** None (no installation required)

## Demo

- **Instructions to run:** The code can be pasted into the Console Window of an R session
- **Expected Output:** Plots of estimated probability densities of various hazard ratios (HRs) (relating to associations between genetic risk scores and mortality)
- **Expected run time for demo on normal desktop computer:** 15-20 seconds

## Instructions for Use

- **How to run the software on your data:** N/A. The code simulates data under an assumed genetic model for disease pathogenesis.
- **Reproduction instructions:** The code (as is) produces the plots for the null scenario (where there is no direct causal effect of the genetic variants on mortality). Instructions to replicate other plots in the paper are given via comments of the code.
